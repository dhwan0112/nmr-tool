# nmr-tool의 원리

이 문서는 nmr-tool이 스펙트럼 파일에서 화학적 이동, 결합 상수, 적분, 몰비, 질량을 얻는 방법을 설명한다. 각 절은 계산식, 그 식이 성립하는 조건, 결과를 믿을 수 있는 범위의 순서로 썼다. 예로 든 숫자는 [`examples/cm3191`](../examples/cm3191)의 스펙트럼에서 나온 값이다. 절마다 제목 아래에 그 계산을 하는 코드로 가는 링크를 달았다.

## 1. 다루는 범위

NMR 측정은 자유 유도 감쇠(FID)를 기록하고, 이를 푸리에 변환한 뒤 위상을 맞춰 스펙트럼을 만든다. nmr-tool은 이 과정을 다시 하지 않는다. 분광기 소프트웨어(TopSpin)가 이미 변환하고 위상을 맞춰 저장한 실수부 스펙트럼 `pdata/1/1r`을 읽어 그 뒤의 분석만 한다.

따라서 창 함수(apodization), 영 채움(zero filling), 위상 보정은 측정 당시 설정 그대로다. 위상이 틀어진 스펙트럼은 이 도구로 고칠 수 없고, 그런 스펙트럼의 적분은 믿을 수 없다.

## 2. 파일에서 스펙트럼으로

코드: [`read_jcamp`](../nmrtools/bruker.py#L24-L44), [`_load_dir`](../nmrtools/bruker.py#L151-L183), [`_find_pdata`](../nmrtools/bruker.py#L130-L148), [`Spectrum.hz_per_point`](../nmrtools/bruker.py#L56-L59)

`1r`은 세기값만 차례로 적은 이진 파일이다. 축 정보는 같은 폴더의 `procs`에 글자로 적혀 있다. 폴더나 zip 안에 실험이 여러 개 있으면 정렬 순서로 첫 번째를 읽고 나머지 번호를 경고로 알려 준다. 다른 실험은 `expno`로 고른다. 읽을 때 쓰는 매개변수는 다음과 같다.

| 매개변수 | 뜻 |
|---|---|
| `BYTORDP` | 바이트 순서 (0이면 리틀 엔디언) |
| `DTYPP` | 자료형 (0이면 32비트 정수, 2면 64비트 실수) |
| `NC_proc` | 세기의 2의 지수 배율 |
| `SI` | 점의 개수 |
| `SF` | 스펙트럼의 기준 주파수 (MHz) |
| `OFFSET` | 첫 점의 화학적 이동 (ppm) |
| `SW_p` | 스펙트럼 폭 (Hz) |

세기는 저장된 값 r_k에 2의 NC_proc 제곱을 곱해 얻는다.

```
y_k = r_k × 2^NC_proc
```

k번째 점(k = 0, 1, …, SI − 1)의 화학적 이동은 다음과 같다.

```
δ_k = OFFSET − k × (SW_p / SF) / SI
```

SW_p를 SF로 나누면 스펙트럼 폭이 ppm 단위가 되고, 이를 SI로 나누면 점 사이 간격이 된다. 첫 점이 가장 큰 ppm이고 뒤로 갈수록 작아지므로, 배열 순서가 그림의 왼쪽에서 오른쪽 순서와 같다.

점 사이 간격을 Hz로 바꾼 값이 디지털 분해능이다.

```
분해능 (Hz/점) = |δ_1 − δ_0| × SF = SW_p / SI
```

예시 자료에서는 다음과 같다.

| 분광기 | 점 개수 | 폭 | 분해능 |
|---|---|---|---|
| 400 MHz | 32768 | 20.0 ppm (8013 Hz) | 0.24 Hz/점 |
| 500 MHz | 65536 | 20.0 ppm (9998 Hz) | 0.15 Hz/점 |

선 위치와 결합 상수의 정밀도는 이 값을 기준으로 생각하면 된다.

세기의 단위는 임의다. 수신기 이득, 시료 농도, 스캔 횟수에 따라 달라지므로 서로 다른 스펙트럼의 세기를 그대로 비교할 수 없다. 한 스펙트럼 안에서 신호끼리의 비만 뜻이 있다.

## 3. 화학적 이동의 기준 맞추기

코드: [`Spectrum.referenced`](../nmrtools/bruker.py#L77-L87), [`Spectrum.refined_position`](../nmrtools/bruker.py#L66-L74), [`do_ref`](../nmrtools/cli.py#L211-L226)

분광기는 중수소 잠금(lock) 신호로 축을 잡는다. 이 축은 대개 0.02 ppm쯤 어긋나 있다. 예시의 CDCl₃ 스펙트럼에서 잔류 CHCl₃ 선은 7.283에서 7.285 ppm 사이에 기록되어 있었고, 약속된 값은 7.26 ppm이다.

`ref`는 지정한 구간에서 가장 높은 점을 찾아 그 점이 목표값에 오도록 축 전체를 같은 양만큼 옮긴다.

```
찾은 위치 = 구간 [a, b] 안에서 y_k가 가장 큰 점을 5절의 포물선으로 보간한 위치
이동량    = 목표값 − 찾은 위치
δ'_k      = δ_k + 이동량
```

가장 높은 격자점을 그대로 쓰면 점 간격의 절반(400 MHz에서 0.0003 ppm)까지 어긋날 수 있다. 선 위치를 읽을 때와 같은 보간을 쓰므로, 기준 선을 `peaks`로 다시 읽으면 목표값이 그대로 나온다.

축을 늘이거나 줄이지 않고 평행 이동만 하므로 선 사이의 간격, 곧 결합 상수는 바뀌지 않는다.

이 방법은 구간에서 가장 높은 점이 기준 신호라는 가정에 기대고 있다. 기본 구간 7.20–7.35 ppm에 시료의 방향족 신호가 들어오면 엉뚱한 선을 기준으로 삼게 된다. 예시에서는 두 가지 방법으로 피했다.

Suzuki 생성물은 방향족 선이 7.37 ppm 위쪽에 있어서 구간을 7.275–7.295 ppm으로 좁혀 CHCl₃ 선만 잡았다. Diels–Alder 첨가 생성물은 방향족 다중선이 CHCl₃ 선을 덮고 있어서 잔류 에틸 아세테이트의 CH₃ 단일선을 2.05 ppm에 맞췄다. 이때 이동량은 −0.024 ppm으로, 같은 분광기의 다른 시료에서 CHCl₃로 구한 값과 같았다.

기준으로 삼을 선이 없으면 보정하지 않는 편이 낫다. 전달 수소화 반응 시료는 반응 용매가 많이 섞여 모든 신호가 순수한 CDCl₃에서의 값보다 0.1 ppm쯤 낮은 장 쪽에 있었고, 어느 선도 믿을 만한 기준이 아니어서 기록된 값을 그대로 두었다.

## 4. 기준선

코드: [`Spectrum.baseline_offset`](../nmrtools/bruker.py#L89-L91), [`Spectrum.baseline_poly`](../nmrtools/bruker.py#L93-L107), [`do_baseline`](../nmrtools/cli.py#L228-L258)

적분은 세기를 더하는 계산이므로 신호가 없는 곳의 세기가 0이어야 한다. 기준선이 0에서 h만큼 떠 있으면 폭이 n점인 적분 구간(아래에서는 창이라 부른다. 1절의 창 함수와는 다른 것이다)의 적분에 h × n이 그대로 더해진다. 작은 신호를 넓은 창으로 적분할수록 이 오차의 비중이 커진다.

보정 방법은 두 가지다.

`baseline offset`은 신호가 없는 구간(기본 8.5–10.0 ppm)의 세기 중앙값을 전체에서 뺀다.

```
y'_k = y_k − median{ y_j : δ_j가 구간 안 }
```

평균 대신 중앙값을 쓰는 것은 그 구간에 작은 신호가 끼어 있어도 값이 덜 끌려가기 때문이다. 기준선이 평평하게 떠 있을 때 쓴다.

`baseline poly`는 신호가 없는 구간 여러 곳의 점들에 다항식을 최소제곱으로 맞추고, 그 다항식을 스펙트럼 전체에서 뺀다. 기본은 2차다.

```
p(δ) = c_0 + c_1 δ + … + c_n δ^n
c    = Σ_j [y_j − p(δ_j)]² 을 가장 작게 하는 계수 (j는 구간 안의 점)
y'_k = y_k − p(δ_k)
```

기준선이 완만하게 휘어 있을 때 쓴다. 구간 안에 신호가 있으면 다항식이 그 신호를 따라가 주변 적분이 틀어지므로 구간은 화합물마다 직접 확인해야 한다. 기본 구간은 linalool 스펙트럼에 맞춰 고른 것이다.

차수를 높이면 넓은 신호의 밑동까지 기준선으로 보고 깎아낼 수 있다. 2차로 부족하면 차수를 올리기보다 구간을 다시 고르는 편이 안전하다.

## 5. 선 위치

코드: [`pick_lines`](../nmrtools/analysis.py#L15-L32), [`Spectrum.refined_position`](../nmrtools/bruker.py#L66-L74), [`do_peaks`](../nmrtools/cli.py#L279-L288)

`peaks`는 지정한 구간에서 양옆 점보다 높은 점을 모두 찾고, 그중 높이가 구간 최댓값의 일정 비율(기본 0.15) 이상인 것만 남긴다. 이 문턱값이 잡음과 작은 불순물 선을 걸러낸다.

```
y_(k−1) < y_k > y_(k+1)    그리고    y_k ≥ 0.15 × max(구간 안의 y)
```

선의 개수를 n으로 지정하면 이 가운데 높은 순서로 n개만 남긴다.

찾은 점은 격자 위의 점이라 위치가 점 간격만큼 거칠다. 그래서 꼭짓점과 양옆 두 점을 지나는 포물선을 그려 그 꼭짓점을 선 위치로 삼는다. 세 점의 세기를 왼쪽부터 a, b, c라 하면 꼭짓점은 가운데 점에서 다음만큼 떨어져 있다.

```
d = (a − c) / (2 × (a − 2b + c))    (단위: 점 간격)
```

세 점을 지나는 포물선 y = b + (c − a)x/2 + (a − 2b + c)x²/2 의 기울기가 0이 되는 x가 d다. 선 위치는 가운데 점의 δ_k에 d만큼의 점 간격을 더한 값이다.

```
δ_선 = δ_k + d × (δ_(k+1) − δ_k)
```

d는 −0.5와 0.5 사이의 값이다. 이 보간으로 선 위치를 점 간격보다 잘게 읽을 수 있다. 다만 두 선이 선폭 안쪽으로 겹쳐 있으면 꼭짓점 자체가 서로 끌려가므로 보간해도 참값이 나오지 않는다.

## 6. 결합 상수

코드: [`coupling_constants`](../nmrtools/analysis.py#L35-L46), [`do_j`](../nmrtools/cli.py#L290-L297)

결합 상수(coupling constant) J는 스핀–스핀 결합으로 갈라진 선 사이의 간격을 Hz로 잰 값이다. ppm 차이에 기준 주파수를 곱하면 Hz가 된다.

```
J (Hz) = Δδ (ppm) × SF (MHz)
```

J는 분자의 성질이라 자기장 세기와 무관하다. 같은 10 Hz가 400 MHz에서는 0.025 ppm, 500 MHz에서는 0.020 ppm으로 보인다.

이중선(d)은 두 선의 간격이 J다.

```
J    = (δ₁ − δ₂) × SF
중심 = (δ₁ + δ₂) / 2
```

이중선의 이중선(dd)은 선이 네 개이고, 큰 ppm부터 δ₁, δ₂, δ₃, δ₄라 하면 다음과 같이 구한다.

```
J_작은 = [(δ₁ − δ₂) + (δ₃ − δ₄)] / 2 × SF
J_큰   = [(δ₁ − δ₃) + (δ₂ − δ₄)] / 2 × SF
중심   = (δ₁ + δ₂ + δ₃ + δ₄) / 4
```

같은 결합이 두 번씩 나타나므로 평균을 낸다. 일차 dd의 네 선은 중심에서 ±(J_큰 + J_작은)/2 와 ±(J_큰 − J_작은)/2 만큼 떨어져 있으므로, 위 식에 넣으면 두 J가 그대로 나온다.

일차인지 가늠하는 비는 다음과 같이 계산한다.

```
Δν / J = |δ_A − δ_B| × SF / J_AB
```

이 식은 일차 스펙트럼에서만 맞는다. 결합한 두 핵의 화학적 이동 차이 Δν(Hz)가 J보다 충분히 커야 한다는 조건이고, 보통 Δν/J가 10 이상이면 일차로 본다. 이 비가 작아지면 안쪽 선이 커지고 바깥쪽 선이 작아지는 지붕 효과가 나타나며, 선 간격이 J와 달라진다.

Diels–Alder 첨가 생성물의 Hb(3.18 ppm)와 Hc(2.65 ppm)는 500 MHz에서 267 Hz 떨어져 있고 둘 사이의 J는 12.3 Hz다. 비가 22이므로 일차로 다뤄도 된다. 이 세 양성자에서 얻은 값은 다음과 같다.

| 양성자 | δ (ppm) | J (Hz) |
|---|---|---|
| Ha | 4.30 | 10.0, 6.5 |
| Hb | 3.18 | 12.3, 10.0 |
| Hc | 2.65 | 12.3, 6.5 |

결합은 두 핵이 함께 갖는 값이므로 한쪽에서 읽은 J가 상대 쪽에서도 나와야 한다. 12.3 Hz는 Hb와 Hc에, 10.0 Hz는 Ha와 Hb에, 6.5 Hz는 Ha와 Hc에 각각 나타난다. 이렇게 짝이 맞는지 보는 것이 신호 지정(assignment)을 검증하는 가장 간단한 방법이다.

결합 상수의 정밀도는 디지털 분해능과 선폭으로 정해진다. 포물선 보간을 거쳐도 0.1 Hz보다 잘게 적을 근거는 없다.

## 7. 적분

코드: [`integrate`](../nmrtools/analysis.py#L49-L55), [`do_integrate`](../nmrtools/cli.py#L300-L316)

`integrate`는 창 안의 세기를 모두 더한다.

```
I = Σ y_k    (lo ≤ δ_k ≤ hi 인 모든 k)
```

점 간격 Δδ가 일정하므로 넓이는 I × Δδ이고, 한 스펙트럼 안에서 I의 비는 넓이의 비와 같다. 기준선이 h만큼 떠 있으면 창 안의 점이 n개일 때 I에 h × n이 더해진다.

¹H NMR에서 신호의 넓이는 그 신호를 내는 양성자 수에 비례한다. 한 스펙트럼 안에서 적분을 양성자 수로 나눈 값끼리 비교하면 분자 수의 비가 된다. 이 관계가 성립하려면 몇 가지 조건이 필요하다.

첫째는 이완이다. 펄스를 준 뒤 자화가 평형으로 돌아오는 데는 T₁의 몇 배가 걸린다. 다 돌아오기 전에 다음 펄스를 주면 T₁이 긴 양성자의 신호가 덜 나온다. 펄스 각(flip angle) θ, 반복 시간 T_R로 되풀이할 때 정상 상태의 신호는 다음에 비례한다.

```
sin θ × (1 − E) / (1 − E cos θ),    E = exp(−T_R / T₁)
```

예시 자료는 모두 30° 펄스를 쓰는 `zg30`으로 측정했다. 펄스 각을 작게 잡는 것은 이 손실을 줄이기 위해서다. 예를 들어 반복 시간이 5 s이면 T₁이 1 s인 양성자는 신호의 99.9%가 나오지만 T₁이 5 s인 양성자는 93%만 나온다. 방향족 양성자나 작은 분자의 양성자는 T₁이 길 수 있다. 정량 측정에서는 반복 시간을 가장 긴 T₁의 다섯 배 이상으로 잡지만, 일상 측정은 그렇지 않다. README에서 몰비를 ±10%로 보라고 한 근거가 이것이다.

둘째는 창의 폭이다. 로런츠형(Lorentzian) 선은 꼬리가 길다. 반치폭이 w인 선을 중심에서 ±a까지 적분하면 전체 넓이 가운데 다음 비율만 들어온다.

```
(2/π) × arctan(2a / w)
```

반치폭 1 Hz인 선을 ±20 Hz까지 적분하면 98.4%다. 비교하는 신호들의 창을 선폭에 견줘 비슷한 비율로 잡으면 이 손실은 비에서 상쇄된다.

셋째는 ¹³C 위성 봉우리(satellite)다. 탄소의 1.1%는 ¹³C이고, 여기에 붙은 양성자는 ¹J(C,H)만큼 갈라져 본 신호 양쪽에 0.55%씩 따로 나타난다. ferrocene에서는 이 위성이 4.389와 3.953 ppm에 있고, 간격 0.436 ppm에 400.23 MHz를 곱하면 175 Hz다. 위성을 한 신호에서는 창에 넣고 다른 신호에서는 빼면 1%쯤의 차이가 생긴다. 예시의 창 4.05–4.30 ppm은 두 위성을 모두 뺀 것이다.

넷째는 겹침이다. 창 안에 다른 화합물의 신호가 있으면 그만큼 더해진다. 그래서 화합물마다 다른 신호와 떨어져 있는 공명 하나를 골라 적분한다. 전달 수소화 반응 시료에서 acetophenone의 CH₃ 단일선(2.68 ppm 부근)은 다른 신호와 겹쳐 있어 쓰지 않았고, 8.07 ppm의 ortho 양성자 두 개를 썼다.

## 8. 몰비

코드: [`Component.n`](../nmrtools/analysis.py#L67-L70), [`do_integrals`](../nmrtools/cli.py#L318-L332)

화합물 i에서 고른 신호의 적분을 I_i, 그 신호의 양성자 수를 n_i라 하면

```
N_i = I_i / n_i
```

가 그 화합물의 상대 몰수다. 두 화합물의 몰비는 N의 비다.

```
몰비(i : j) = N_i / N_j = (I_i / n_i) / (I_j / n_j)
몰분율 x_i  = N_i / Σ_j N_j
```

`integrals` 표의 ratio 열은 첫 행을 기준으로 한 N_i / N_1 이다. 이성질체 비를 백분율로 적을 때는 몰분율에 100을 곱한다.

4-*tert*-butylcyclohexanone의 환원에서는 두 부분입체이성질체의 H-1 신호가 떨어져 있다. trans 알코올의 H-1은 축 방향이라 이웃한 축 방향 양성자 둘과 크게 결합하고(약 11 Hz) 넓은 다중선으로 3.51 ppm에 나온다. cis 알코올의 H-1은 적도 방향이라 결합이 모두 작고 좁은 다중선으로 4.03 ppm에 나온다. 둘 다 양성자 하나이므로 적분의 비가 곧 이성질체 비다. 적분이 1.000과 0.261이어서 trans : cis는 1.000 / 0.261 = 3.8 : 1이고, 백분율로는 1.000 / 1.261 = 79%와 0.261 / 1.261 = 21%다.

내부 표준을 쓸 때도 같은 식이다. 넣은 양을 아는 화합물(예시에서는 mesitylene, CH₃ 9개)의 N을 1로 놓으면 다른 화합물의 N이 표준에 대한 몰수가 된다. 표준의 몰수를 곱하면 절대량이 나온다.

```
n_i (mol) = n_표준 × N_i / N_표준
```

ferrocene 예시에서 ferrocene 1 mol당 물 1.87 mol이라는 값도 같은 식에서 나왔다. ferrocene의 Cp 양성자 10개와 물의 양성자 2개로 각각 나눈 값의 비다.

## 9. 질량 보정

코드: [`mass_correction`](../nmrtools/analysis.py#L73-L101), [`_mass`](../nmrtools/cli.py#L376-L384), [`do_mass`](../nmrtools/cli.py#L386-L402)

저울로 잰 질량에는 생성물 말고도 잔류 용매와 부산물이 들어 있다. NMR 몰비를 알면 그 질량을 성분별로 나눌 수 있다.

성분 i의 몰질량을 M_i라 하면 상대 질량은 N_i × M_i이고, 질량 분율과 질량은 다음과 같다.

```
w_i  = N_i M_i / Σ_j (N_j M_j)
m_i  = w_i × m_전체
n_i  = m_i / M_i              (mol; 1000을 곱하면 mmol)
몰비 = N_i / N_목표
```

수율은 생성물의 n_i로 다시 계산한다.

```
수율 (%) = n_생성물 / n_이론 × 100
```

n_이론은 한계 반응물의 몰수에 화학량론 계수를 곱한 값이다. 적분이 음수로 나온 성분은 `mass` 명령에서 0으로 센다. `mass` 명령과 `mass_correction` 함수가 이 계산을 하며, 성분 개수에는 제한이 없다.

이 계산은 시료가 적분표에 넣은 성분만으로 이루어져 있다고 가정한다. ¹H 신호가 없거나 세지 않은 성분, 곧 물, 무기염, 실리카, 중수소화 용매는 분모에 들어가지 않는다. 그런 성분이 있으면 생성물의 질량 분율은 실제보다 크게 나온다. 계산된 값은 생성물 질량의 상한으로 읽어야 한다.

몰비에서 질량 분율로 넘어갈 때 몰질량이 곱해지므로, 몰비로는 작아 보이는 무거운 불순물이 질량으로는 큰 몫을 차지할 수 있다. 반대로 가벼운 용매는 몰비에 견줘 질량 몫이 작다.

## 10. 그림의 세로축

코드: [`plot_panels`](../nmrtools/plots.py#L46-L102), [`plot_stack`](../nmrtools/plots.py#L116-L200), [`Spectrum.normalised`](../nmrtools/bruker.py#L109-L111)

세기의 단위가 임의이므로 그림의 세로 눈금은 뜻이 없고, 그리지 않는다. 대신 무엇에 맞춰 높이를 정했는지가 중요하다.

`plot`은 ppm 구간마다 칸을 하나씩 만들고 칸마다 가장 높은 선에 맞춰 세로를 잡는다. 칸이 다르면 배율도 다르므로 서로 다른 칸의 선 높이는 비교할 수 없다. `with=`로 겹쳐 그린 스펙트럼끼리는 같은 절대 배율을 쓴다.

```
그린 높이 = y_k / max(그 칸에 그린 모든 스펙트럼의 y)
```

`stack`은 스펙트럼을 위아래로 쌓고, 각 스펙트럼을 `norm=` 구간에서 가장 높은 점이 1이 되도록 나눈다. 이 구간을 내부 표준이나 공통 신호에 두면 스펙트럼 사이에서 나머지 신호의 높이를 견줄 수 있다. 전달 수소화 반응 예시는 mesitylene의 CH₃ 선에 맞췄기 때문에 두 시료의 acetophenone 신호 높이를 바로 비교할 수 있다. 기준 신호보다 높은 선은 1.12에서 잘린다.

```
그린 높이 = min( y_k / max(norm 구간의 y), 1.12 ) + 1.25 × (아래에서 센 순서, 0부터)
```

`zoom=`은 지정한 구간을 세로로 몇 배 키워 따로 그린다. 배율은 그림에 적힌다.

```
확대 칸의 높이 = y_k / max(norm 구간의 y) × 배율    (0.50까지만 보임)
```

ferrocene 예시의 80배 확대에서 본 신호가 위로 잘려 보이는 것은 이 때문이다.

높이와 넓이는 다르다. 같은 넓이라도 선폭이 넓거나 여러 갈래로 갈라진 신호는 낮게 보인다. 양을 말할 때는 그림의 높이가 아니라 적분을 써야 한다.

## 11. 한계

처리된 1차원 스펙트럼만 읽는다. 푸리에 변환, 위상 보정, 창 함수는 다루지 않는다.

적분은 창 안의 단순 합이다. 겹친 신호를 선 모양 맞춤(line-shape fitting)으로 나누는 기능은 없다.

결합 상수는 일차 가정 아래 이중선과 이중선의 이중선에서만 계산한다. 삼중선, 사중선, 더 복잡한 다중선은 `peaks`로 선 위치를 읽어 직접 계산해야 한다.

일상 측정 조건의 적분은 이완 때문에 정량적이지 않다. 몰비와 그로부터 나온 질량은 ±10% 정도로 본다.

결과를 MestReNova나 TopSpin의 값과 대조해 검증하지는 않았다.
